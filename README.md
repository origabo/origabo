# 📂 Proyectos destacados

## 01. Proyecto Jupiter — Detección de fraude

**Proyecto final de máster (PontIA)**

- Diseño e implementación de un modelo de datos relacional para transformar millones de transacciones JSON en una estructura analítica eficiente y escalable.

- Procesamiento y limpieza de más de 6 millones de transacciones anonimizadas para facilitar el análisis, monitorización y explotación de datos.

- Desarrollo de métricas y KPIs de negocio para identificar patrones operativos, monitorizar sistemas y apoyar la toma de decisiones basada en datos.

- Identificación de errores, incidencias y anomalías en el procesamiento de transacciones mediante análisis exploratorio y detección de patrones.

- Creación de un sistema automatizado de detección de fraude utilizando técnicas de Machine Learning para clasificar operaciones fraudulentas y reducir la validación manual.

**Stack:** Python, Pandas, NumPy, Scikit-learn, SQL, MySQL, JSON, Power BI, Machine Learning, Data Cleaning, Data Visualization
