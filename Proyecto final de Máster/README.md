# 🚨 PROYECTO FINAL DE MÁSTER: Detección de Fraude

## 📌 Alcance del Proyecto

Desarrollo de un sistema de detección de transacciones fraudulentas para una entidad bancaria mediante análisis de datos, modelado relacional y técnicas de Machine Learning.

---

# 🏦 Contexto

La empresa **Pontia Bank S.L.** necesita desarrollar un sistema capaz de detectar transacciones fraudulentas entre los millones de operaciones que procesa diariamente.

Actualmente, la compañía almacena las transacciones en archivos JSON mediante un sistema NoSQL, sin una infraestructura adecuada para el análisis, monitorización y explotación de datos.

Para ello, se ha realizado una extracción anonimizada de más de **6 millones de transacciones** correspondientes a los últimos 30 días, identificando manualmente aquellas operaciones consideradas fraudulentas.

El objetivo principal es automatizar la detección del fraude y construir una infraestructura de datos que permita tomar decisiones estratégicas basadas en datos.

---

# 🎯 Objetivos del Proyecto

- Diseñar e implementar un modelo de datos relacional.
- Procesar y transformar millones de registros transaccionales.
- Detectar errores e incidencias operativas dentro del sistema.
- Automatizar la detección de fraude mediante Machine Learning.
- Generar métricas y KPIs útiles para negocio.
- Proponer soluciones basadas en IA Generativa.

---

# 📊 Entregables del Proyecto

- Jupyter Notebook con análisis completo y respuestas de negocio.
